# Nangcamane ❤️

A romantic mobile-friendly love website made for Nangcamane.

## Files
- `index.html` — the website
- `style.css` — design and animations
- `script.js` — hearts and interactions
- `assets/` — your photos and background video

## Test it
Open `index.html` in Chrome.

## Put it online
Upload the whole folder to a GitHub repository and enable GitHub Pages.
The final link can then be sent through WhatsApp.

Important: keep the `assets` folder together with `index.html`, otherwise the photos/video will not load.
